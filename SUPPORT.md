# Support

Thanks for using futuopend. Here is where to get help.

## Questions and general discussion

Use [GitHub Discussions](https://github.com/shing1211/futuopend/discussions) for:

- How-to and setup questions
- Deployment help (also see [futuopend-deploy](https://github.com/shing1211/futuopend-deploy))
- Ideas, feature discussion, and show-and-tell

## Bug reports

Open an [issue](https://github.com/shing1211/futuopend/issues/new/choose) using the bug report template. Please include your host OS and architecture, Docker version, the image tag, and clear steps to reproduce.

## Security

Do not report security issues publicly. See [SECURITY.md](SECURITY.md) for the private reporting process.

## Scope

This repository builds the Docker image. Problems with FutuOpenD itself, Futu's servers, or the various SDKs should be reported to their respective projects, not here.
